BPI-Bit-S2 + PlanetX -- async 5x5 LED display & A/B/C/D button library.
Part of a LightTower challenge PoC (CircuitPython on ESP32-S2).

Requires: CircuitPython 10.3.0, board bpi_bit_s2.
Bundle libraries: asyncio, adafruit_ticks (circup install asyncio).
board / neopixel / keypad / rainbowio are built in / frozen on this firmware.

Source, docs, tests: https://github.com/AlexHentschel/circuitpython-experiments/tree/master/2026-09_Exp16_BPI-Bit-S2_CircuitPy_PlanetX
